# ChatWave — Web Messenger 💬

ChatWave is a web messaging application I'm building to make communication simple and convenient. It lets users connect, manage conversations, and communicate through a clean, modern interface.

## 🎬 Project Demo

[▶️ Watch ChatWave Demo](https://github.com/Prashantspatil3952/chatwave-web-messenger/blob/main/ChatWave-Demo.mp4)

🌐 **Live Demo:** [ChatWave Web Messenger](https://chatwave-web-messenger.vercel.app/)

## ✨ Features

- 🔐 User registration and login
- 📧 Six-digit OTP verification for account registration and password recovery
- 👥 Find users by email or user ID
- 💬 Create and manage conversations
- ⚡ Real-time communication using Socket.IO
- 📞 Calling interface
- 🗄️ Store user and conversation data in MongoDB
- 📱 Responsive user interface

*The project is still in development, and some features may require further testing.*

## 🛠️ Tech Stack

- **Frontend:** React, Vite, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Real-Time Communication:** Socket.IO
- **Authentication:** JWT and bcrypt
- **Deployment:** Vercel and Render
